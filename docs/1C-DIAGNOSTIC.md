## Как устроена проверка

1С на этом компьютере отправляет каталог в отдельный приёмник `http://127.0.0.1:5179/exchange`. Интернет для этого соединения не нужен. Адрес работает только на компьютере приёмника: если 1С запускается на другом устройстве, эта схема не подходит. Основной сайт на5173 и опубликованные сайты не используются.

Приёмник поддерживает только каталог. После авторизации принимает исходные байты файлов/частей и сохраняет их в исключённой из Git папке. Он не разбирает XML, не распаковывает ZIP, не меняет товары, цены, остатки или заявки и не передаёт заказы в1С. Принятые файлы нельзя скачать через HTTP.

По [официальному протоколу1С](https://v8.1c.ru/tekhnologii/obmen-dannymi-i-integratsiya/standarty-i-formaty/protokol-obmena-s-saytom/) ответ `success` на `file` подтверждает запись файла/части, а на `import` — успешное окончание обработки файла. Поэтому диагностический приёмник на **каждый import возвращает**:

```text
failure
Diagnostic capture only; import disabled
```

Это ожидаемая остановка проверки, не признак готового обмена. `progress` и фиктивный `success` при импорте не используются. Отсутствие подтверждения импорта не доказывает, что конкретная1С не изменит служебные записи/регистрации обмена. Настройка узла и ручной запуск согласуются как отдельное конкретное действие; учётных операций ради теста не выполнять.
