## Как устроено

`data/*.json` → серверный `lib/catalog.ts` (индекс, фильтры, сортировка, пагинация) → страницы в `app/` и `GET /api/catalog` → клиентские компоненты. Главная и подборки дополнительно используют `collection-selection.ts`, `collections.ts` и `autumn-editorial.ts`. `pricing.ts` форматирует существующие цены; `product-images.json` накладывает три фото на карточки.

`StoreShell` содержит общую навигацию и контекст корзины/избранного. `ProductDetail` выбирает конкретный вариант и передаёт его в корзину. `personal-pages.tsx` показывает снимки товаров и вариантов из localStorage. `storefront.tsx` загружает недавно просмотренные товары через API. Серверных записей заказа и пользовательской базы нет.

## Подтверждённые ошибки и локальный объём исправлений

| Проблема до изменения | Доказательство и последствие | Исправление этапа 0 |
|---|---|---|
| API усекает `ids` после 500 | `app/api/catalog/route.ts` использует `.slice(0,500)`, избранное лимита не имеет. Вызов обработчика с 501 существующим ID даёт 500, исключённый `gc005212` отдельным запросом находится. | Удалить тихое усечение, сохранить проверку формата ID и пагинацию; использовать Set при фильтрации. |
| Корзина и избранное читаются/пишутся одним блоком try | `StoreShell`: ошибка JSON/доступа по первому ключу прерывает чтение другого, а готовность включает немедленную перезапись обоих значений. Ошибка первого setItem мешает второму. | Независимые операции с ключами; не перезаписывать сохранённые данные только из-за монтирования компонента; сообщать об ошибке сохранения после действия. |
| Валидация корзины проверяет только truthy ID и положительное число | `{product:{id:42},variant:{id:7},quantity:1}` проходит фильтр, затем `product.id.toUpperCase()` в Bag вызывает TypeError. Дробные количества и значения больше 99 также проходят. | Проверять структуру необходимых полей Product/Variant, принадлежность варианта и целое количество 1–99. Корректные старые снимки сохранять без пересчёта цены/смены варианта. |
| История просмотров принимает произвольные элементы массива | `RecentViewed`: массив с объектом `{toString:0}` проходит Array.isArray и ломает join до fetch. В `ProductDetail` повреждённый JSON блокирует запись нового просмотра. Очистка поисков не обрабатывает ошибку removeItem. | Общие функции безопасного чтения строковых списков и записи; сбой одного ключа не блокирует остальные. |
| Назад в избранном после сокращения последней страницы | При 49 товарах на странице 3 удаление последнего даёт result.page=2, но внутреннее page остаётся 3. Первый «Назад» оставляет отображаемую страницу 2. | Переключать страницы относительно реально возвращённого result.page. |

Изменения не требуют бизнес-решений, новых сервисов, изменения формата хранения или миграции. Повреждённые данные не заменяются автоматически при загрузке; проверка защищает интерфейс, а исходная запись остаётся до явного изменения пользователем соответствующего списка. В этом этапе не меняется политика цен/наличия или состав каталога.

XLSX и исходная переписка не лежат в public. Приложение не выполняет SQL или server actions; D1/R2 отключены.
