# Проект на GitHub

Поручение владельца от 13 октября 2026: публичный репозиторий `grace` в аккаунте `gracecosmeticsru`, с обновлением после каждой выполненной задачи.

Адрес: https://github.com/gracecosmeticsru/grace

## Что хранится в репозитории

Исходники frontend и backend, конфигурация, lockfile, тесты, SQL-миграции, полный файловый каталог, фотографии и прочие файлы `public/`, исходные материалы `materials/` (включая имеющийся XLSX), документация и доступная история разработки. Восемь существовавших локальных коммитов сохраняются; накопленные после них изменения входят в общий исходный снимок. Прошлые задачи не получают вымышленную отдельную историю коммитов задним числом.

Рабочая папка остаётся `D:\grace`. Резервная копия на C: не меняется.

## Что остаётся только локально

- Секреты `.env*`, `.dev.vars*`, ключи и настройки доступа.
- `.wrangler/` и базы заявок; рабочая облачная D1 также не является частью Git-репозитория.
- `node_modules/`, сборки, кеши TypeScript и локальные настройки среды.
- `artifacts/`: временные скачивания, журналы, локальные контрольные снимки и снимки экрана. Отчёты в `docs/` сохраняются, но их ссылки на локальные доказательства могут требовать исходного checkout.
- `.sites-runtime/`, `.codex/`, `.agents/`, `.unlazy/`, `outputs/`, `work/` и скрытое машинное состояние Graphify. Сам граф и его документация сохраняются.

Эти файлы не удаляются с компьютера. GitHub служит историей исходников и материалов, а не резервной копией секретов, заявок или браузерного localStorage. Недостающий исходный `Grace_1C_FINAL_IMPORT_5051.xlsx` по-прежнему отсутствует; его импортированный результат сохранён в каталоге.

## После каждой задачи

1. Проверить результат в объёме задачи и обновить соответствующий отчёт.
2. Просмотреть `git status` и diff, проверить новые файлы на секреты; добавить только файлы завершённой задачи.
3. Создать коммит с понятным описанием изменений и отправить его в текущую рабочую ветку `origin`.
4. Сверить локальный SHA с удалённой веткой. В итоговом ответе дать ссылку вида `https://github.com/gracecosmeticsru/grace/commit/<SHA>` и результат проверок.

Правило закреплено в корневом `AGENTS.md` для следующих задач. Это действие при завершении работы агентом, не фоновый сервис: произвольные ручные изменения файлов сами на GitHub не отправляются. При ошибке сети или авторизации коммит остаётся локально до успешного повторного push. Force-push и переписывание истории не используются.

GitHub хранит изменения кода. Обновление опубликованного сайта выполняется отдельно по поручению владельца; в рамках этого переноса автодеплой не подключается.

## Запуск копии

Установить Git и Node.js >=22.13, затем:

```sh
git clone https://github.com/gracecosmeticsru/grace.git
cd grace
npm run install:ci
npm run dev -- --hostname 127.0.0.1
```

Локальная витрина доступна на `http://127.0.0.1:5173/`. Для Telegram, СДЭК и рабочего хранения заявок требуется отдельная настройка среды; действующие секреты из GitHub не восстанавливаются. Ограничения функциональности перечислены в `docs/FRIEND-ORDERS.md` и актуальном начале `AGENTS.md`.
