# Ответы владельца перед продолжением 10А

Эти решения получены через голосовую задачу 01a1275f-7859-7992-b441-a473976b66b7 после паузы для вопросов. Продолжение 10А разрешено; сначала простой понятный вариант. Исходные 30 промптов сохраняются без правок. При расхождении прежнего плана с этим решением действует этот документ.

1. Доставка только по России.
2. СДЭК: пункт выдачи **и** курьер до двери. Почта также сохраняется. Стоимость рассчитывает менеджер.
3. Последнее прямое решение 11 октября: «без карты просто список пунктов СДЭК». Выбор: полное название города → регион при совпадении названий → небольшой список реальных ПВЗ с адресами и, если API даёт, часами работы; поиск, страницы, загрузка, пустой результат, ошибка и повтор. При смене города прежний пункт сбрасывается. Яндекс и iframe не нужны. Использовать существующие Account/Secure password, перенести самостоятельно из предоставленного снимка; не менять ключи, кабинет и Битрикс (он не опубликован и заказов не принимает). Не угадывать значения и не создавать отправления/тарифы. Это заменяет прежнее требование карты.
4. Небольшой необязательный комментарий к заказу, без дополнительного шага.
5. Менеджер пишет покупателю в WhatsApp. Телефон сопровождается соответствующей подсказкой; проверка регистрации номера в WhatsApp не имитируется.
6. Постоянный хостинг выберем позже. Не покупать и не выбирать его в 10А. Публичная копия остаётся отдельным снимком для проверки.
7. Для автоматических уведомлений **менеджеру о заказах** первым планируется **Telegram**: один простой канал в стандартных бесплатных лимитах. Gmail можно добавить позже, если потребуется. Прежнее требование WhatsApp для этих уведомлений заменено. Это не меняет WhatsApp для связи менеджера с покупателем и не меняет канал подписок о поступлении в этапе 11.
8. Покупатель оформляет и получает подтверждение на сайте; сервер сохраняет заявку и сам уведомляет менеджера. Никакого перехода покупателя в мессенджер и ручной отправки вместо этого сценария.

Приём настоящих заявок остаётся закрытым до надёжного сохранения 10Б и зависимых условий плана. Уведомления — в 10В, реальные тестовые сообщения только по отдельному разрешению на согласованного получателя. Текущее поручение ограничено 10А, затем остановиться перед 10Б. Работа только в D:/grace; облако, резервная копия C, фотографии/тексты, 1С, кабинет и онлайн-оплата не затрагиваются.
