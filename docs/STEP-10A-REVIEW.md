11 октября 2026, рабочий checkout `D:/grace`. **Локальная часть проверена; полный 10А не закрыт: живой API СДЭК недоступен по сети.** Всего завершено 13/30, 10Б не начат.

## Изменение по последнему решению владельца

Официальная карта заменена поиском полного названия населённого пункта, выбором региона и компактным списком ПВЗ по шесть. Есть поиск по улице/коду, страницы, выбор стабильного кода и адреса, часы только из API, загрузка/ошибка/повтор/пустой результат. Смена города сбрасывает ПВЗ; запоздавшие ответы не подменяют новый результат. Яндекс, iframe и CDN виджета больше не используются.

Курьер СДЭК и Почта России остаются отдельными ветками. Имя, телефон WhatsApp, комментарий, точные варианты и сумма сохранены. Настоящих заявок, отправлений, сообщений или ложной благодарности нет; корзина не очищается. Доставка без вымышленных тарифов, стоимость уточняет менеджер.

OAuth не подтверждён: два ограниченных запроса и независимая IPv4-проверка не получили соединения; живой маршрут поиска города вернул безопасный503 через10053мс. Это не доказательство неверной пары. В кабинет и Битрикс изменений не внесено, ключи не перевыпускались. **Когда соединение с api.cdek.ru восстановится, повторить OAuth и получить реальный город/ПВЗ через этот интерфейс.** Пара уже локально заполнена, дополнительный ввод владельцем не требуется.

Unlazy: 5 критериев выполнены; G6 передан как незакрытая внешняя проверка. После этого объёма остановиться перед10Б. Облачные версии и резервная папкаC не изменялись. Хранилище/Telegram/1С относятся к следующим согласованным этапам.

## Повторная визуальная проверка снимков — 11 октября

Прежний checkout-list-mobile-390.jpg оказался JPEG1264×2162 с настольной компоновкой и повторяющимися секциями. Ошибка была в артефакте full-page-захвата; его нельзя использовать как доказательство мобильного вида. Старая склейка перенесена в checkout-fullpage-invalid.jpg, прежний канонический путь заменён проверенным отдельным кадром доставки. Full-page-кадр фикстур также исключён из доказательств; ссылок на него как готовый мобильный результат больше нет.

Теперь после каждой смены viewport выполнялась отдельная проверка AX/DOM, прокрутка завершалась до захвата; снимок видимой области делался в следующем вызове. Все четыре сохранённых JPEG открыты через view_image.
