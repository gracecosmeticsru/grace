## Реализация и проверка

[scripts/one-c-mapping.mjs](../scripts/one-c-mapping.mjs) — чистая функция rehearseMappings для уже нормализованных JSON-записей, без сетевых запросов, записи в каталог, базу или активации. Единственные вызывающие стороны сейчас — [тесты](../tests/one-c-mapping.test.mjs) и локальный диагностический запуск. Код приложения его не использует.

Функция проверяет источник и подтверждение связи, глобальную уникальность внешних/целевыхID и принадлежность варианта карточке. НеизвестныеID, повтор offers, конфликтующие/неподтверждённые связи и отсутствующие варианты изолируются с причинами. Пропущенный товар не превращается в ноль. Для сопоставленных строк проверяются единственная выбранная розничная цена, RUB, единица и коэффициент, различие нуля/минуса/нет количества, неизвестный статус; проблемы чисел не стирают подтверждённую идентичность. Любой результат applied=false.

Локальное normalize.py читает сохранённый XML стандартным ElementTree, проверяет SHA256 и отклоняет DTD/entities. В исходном полном offers у цены нет отдельного элемента Единица: в этом образце используются базовая796/Штука/PCE, Пересчет796/коэффициент1 и коэффициент цены1. Только для этого наблюдаемого случая нормализация разрешает PCE из базовой единицы; rawUnit=null и unitOrigin сохраняются. Это не универсальныйCommerceML-парсер и не готовыйHTTP-приёмник9В.

Проверки: 13/13 тестов node --test tests/one-c-mapping.test.mjs; локальный check-real.mjs PASS; независимое чтение кода и сверка всех 4371 исходных записей PASS. Проверка обнаружила два пограничных случая округления: коэффициент 1.0000000000000001 и отрицательное количество настолько малое, что Number превращает его в −0. Оба исправлены и закреплены отдельными тестами; измеренные результаты фактической выгрузки не изменились. Контрольные суммы1558файлов data/public/materials, прежних захватов и подготовки неизменны; новых файлов в этих защищённых областях нет. Graphify обновлён AST-only, без внешнегоAPI; ранее изменённые/generated файлы графа исключаются из этого коммита. Сборка и визуальная приёмка не требуются для отдельного офлайн-инструмента без изменения приложения.
