## Где хранятся данные

Каталог обслуживается из локальных JSON через `lib/catalog.ts` и `app/api/catalog/route.ts`. Подключённой серверной базы, внешнего API товаров, серверной записи заказов или загрузок не обнаружено. В `db/schema.ts` нет таблиц; `db/index.ts` — неиспользуемая заготовка; D1-пример находится в `examples/`. В настройках Sites список runtime-переменных пуст (ревизия 0). Для запуска этой версии секреты не требуются.

Изображения страниц находятся в `public/images/`; загрузка внешнего CDN для них не нужна. Файл `docs/product-image-sources.json` также перечисляет отвергнутый кандидат Anua 77+ Hyaluron, который не используется сайтом. Его отсутствие не является потерей работающего изображения.

Корзина, избранное, недавние поиски и просмотренные товары хранятся отдельно в браузере посетителя: `grace-bag`, `grace-favorites`, `grace-searches`, `grace-viewed`. Эти записи привязаны к исходному адресу сайта и конкретному устройству. Они не входят в Git или каталог и **не перенесены с телефона**. Для их переноса нужен экспорт этих четырёх значений из браузера, где пользователь открывал сайт. Пустая корзина на localhost не означает потерю каталога. Автоматического переноса данных всех посетителей при такой архитектуре нет.

Его нет в экспортированной переписке, в репозитории или среди подходящих файлов в Downloads, Documents и Desktop. Результат его обработки уже содержится в `data/products.json`, поэтому он не нужен для просмотра или работы текущего сайта. Но для повторного запуска `scripts/import-catalog.py` и полного архива исходных Excel-материалов нужен этот оригинальный файл. Заменяющая таблица по догадкам не создавалась.

Таблица с ними сохранена целиком; логика backend не менялась.
5. 49 карточек без категории уже присутствовали в исходной версии. Таблица включает «Уход за полостью рта» и «Подарки», которых нет в пользовательских шести разделах.
