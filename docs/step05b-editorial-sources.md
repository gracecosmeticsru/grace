## Изображения и недостающие материалы

- Обложки новых гайдов используют существующие редакционные `ritual.png` и `hydration.png` из `public/images/autumn-editorial/`. Это иллюстрации из прежнего материала, а не фотографии конкретных товаров. Корневой агент отдельно проверяет соответствие темам и кадрирование.
- `data/product-images.json` содержит прежние реальные изображения Anua, Rare Beauty и Tom Ford; фотографии этапа 5А учтены отдельно в `docs/step05a-photo-sources.json`. Из выбранных здесь товаров там есть точные фотографии Anua, Dr. Althea и Sol de Janeiro. Подстановка фото другого объёма Hempz не допускается.
- Новые фотографии не искались и не генерировались. Для остальных конкретных вариантов сохраняется штатное состояние «Фото пока нет». Отсутствие фото не означает отсутствие товара.
- Наличие всех выбранных вариантов в исходном JSON — `unknown`. Его нельзя заменять наличием на внешних сайтах. Карточки используют ранее согласованный механизм покупки и состояния проекта.
- Для расширения гайда о сухости нужны проверенные безотдушечные средства именно для тела и фотографии конкретных вариантов. Это недостаток материалов для расширения, а не скрытая незавершённая подборка.

## Проверка редакционного листа

Выполнены четыре прохода: полные тексты и сопоставления; проверка смысла советов и пригодности товаров; проверка источников, дозированного пересказа и вариантов; языковая правка и проверка итогового контракта. Числа слов и машинную проверку корневой агент может повторить через `.unlazy/step-5b/checks.mjs editorial`. Проверка источников остаётся содержательной: существование HTTPS-ссылки само по себе не подтверждает совет.
