# Graphify для Grace

Рабочий проект: `D:\grace`. Graphify подключён штатной командой `graphify codex install`: правила находятся в корневом `AGENTS.md`. Сайт, каталог и замороженные баннеры этапа 4 не изменены.

## Файлы

- `graph.html` — интерактивная карта.
- `graph.json` — граф с источниками и уровнями уверенности связей.
- `GRAPH_REPORT.md` — группы, центральные узлы, вопросы и ограничения.
- `GRAPH_HEALTH.md` / `graph-health.json` — диагностика парсера.
- `extraction-audit.json` — исходные связи до объединения одинаковых пар узлов.
- `setup-validation.json` — итог подключения и проверка сохранности файлов сайта.
- `cost.json` — доступность счётчиков токенов. Реальное потребление агентами не предоставлено; известная сумма 0 не означает бесплатное семантическое извлечение.

## Использование из PowerShell

```powershell
Set-Location D:\grace
$Graphify = 'C:\Users\pc\.local\bin\graphify.exe'
& $Graphify query 'VariantProductCard ProductRail' --budget 1500
& $Graphify explain 'VariantProductCard'
& $Graphify path 'VariantProductCard' 'ProductRail' --undirected
```

Для естественного вопроса агент сначала сопоставляет русскую формулировку с именами в графе, затем проверяет ответ по указанным файлам и строкам. Утверждённые требования и актуальные исходники важнее графа; старые документы и планы этапов не доказывают реализацию.

После изменения кода: `& $Graphify update .` — обновление AST без внешней LLM. После изменения документов используйте `$graphify --update` в задаче Codex: skill обновит и смысловые связи. Автоматическое фоновое наблюдение и git post-commit hook не запускались. Штатный `.codex/hooks.json` содержит PreToolUse `hook-check`, который в этой версии для Codex Desktop является no-op; фактические правила интеграции задаёт `AGENTS.md`.

Область индекса зафиксирована в `.graphifyignore`: актуальный код, конфигурация и документы. Архивные проверки, резервные исходники, исходные материалы и медиа исключены из индекса и сохранены на диске. `.npmrc` пропущен встроенным фильтром чувствительных файлов. Graphify не заменяет содержимое каталога и не меняет сайт.

Для отключения инструкций: `& $Graphify codex uninstall`. Это не команда удаления файлов сайта. Текущий граф можно оставить как справочный артефакт.
