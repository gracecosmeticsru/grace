# Фотографии товаров — этапы6А и6Б

`inventory.json` — 92 уникальные пары фактически показанных товаров/вариантов главной и трёх статей, включая наблюдённую историю.
`manifest.json` — происхождение6А:82 проверенных оригинала,10 пропусков; точные названия, IDs, варианты, источники, размеры и хеши. Поле `preparation` добавляет результат6Б:59 ready,23 blocked,10 source-skipped.
`originals/` — неизменённые байты принятого источника. Это не обработанные и не подключённые к сайту изображения.

`prepared/` — ровно59 принятых файлов1200×1200 WebP, белый фон и единый масштаб. На вариант один файл для общего URL каталога/карточек/PDP в6В. Иных версий для сайта нет. Подходящие дополнительные исходники6Б и отвергнутые пробы — в artifacts/step-6b; не путать их с готовыми файлами.

Проверки из D:/grace: `node .unlazy/step-6b/verify.mjs` и `node .unlazy/step-6b/verify.mjs preservation`. Отчёт6Б: `docs/STAGE-06B-REVIEW.md`, все позиции: `artifacts/step-6b/overview.html`. Предыдущий этап описан в `docs/STAGE-06A-REVIEW.md`. Подключение — следующий отдельный6В. Использовать productId/variantId, не имена файлов. Unknown/Стандарт в каталоге не дополнять объёмом источника по догадке; чужое фото варианта не наследовать.
